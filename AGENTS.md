## Agent skills

### Context management skills

When work spans sessions, involves multiple agents, or is handed off, read the repository-root `SKILL.md` (Context Strict) and follow it. When coordinating work in Orca, also read the repository-root `references/orca.md`. For low-risk, multi-turn work by a single primary agent, read `skills/context-lite/SKILL.md` instead. Do not copy the skill text into this file.

The repository root is the maintained source for Context Strict. `skills/context-strict/` is a generated installable package: `python3 scripts/sync_context_strict_skill.py` rebuilds it from the root, so do not edit it by hand. The scripts and other root-sourced files under `skills/context-lite/` are likewise generated by `python3 scripts/sync_context_tools.py`.
