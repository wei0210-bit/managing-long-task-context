# Context accuracy patterns

A declared success is not evidence of execution. Keep the original command, exit code,
log path, revision and timestamp with the claim. A digest identifies bytes; it does not
prove a test ran or a session took over. Record independent observations when available.

Keep assumptions distinct from verified facts. Preserve uncertainty, stale TTLs,
conflicts and missing originals in reports. Externalized detail keeps its source digest
and event history. Summary overflow includes omitted IDs so readers can consult originals.

Orca handles execution and review. Strict supplies these observations without enforcing
ordered evidence chains, independent review, release or completion decisions.
