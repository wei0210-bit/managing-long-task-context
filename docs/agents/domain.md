# Domain Docs

Before exploring or changing the codebase, read:

- Root `CONTEXT.md`, when it exists.
- Relevant ADRs under `docs/adr/`.

This is a single-context repository.

Do not require these files to exist before work can begin. Domain-modeling work creates them when terminology or architectural decisions need to be recorded.

Use vocabulary defined in `CONTEXT.md`. If proposed work conflicts with an ADR, identify the conflicting ADR explicitly instead of silently overriding it.
