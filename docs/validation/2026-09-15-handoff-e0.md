## 红→绿与复核

在公共入口已有可运行桩后逐项增加行为测试；本轮观察到 16 次针对性 red，随后实现并 green。代表性实际红灯包括：

- 空包：`AssertionError: 'E0_READ' not found in []`。
- bool 代次：`AssertionError: 'E0_SCHEMA' not found in []`。
- unknown 却预期提交：`AssertionError: 'E0_EXPECTATION' not found in []`。
- 修改黄金断言：`AssertionError: 'E0_HASH' not found in []`。
- 重复 JSON 键：原先只有 `E0_HASH`，未给出读取拒绝；补确定性解析后通过。
- 修改 schema 模式：原先抛 `re.error`，补冻结安全模式允许列表后返回 `E0_SCHEMA`。

这些是本轮运行时序记录，不以缺模块／导入失败充当行为红灯；未存每个中间版本，因此下方命令复现的是最终冻结状态，不声称可以单凭本报告重演全部历史 red。

复核时明确初始 phase／controller 与 setup_actions，避免迟到请求和提交丢回执混用代次分母。合成内联文件与引用 hash 已关联；它只证明合成夹具自洽，**不证明其业务内容足以验收**。实际内容／授权／角色核验仍由后续产品实现及独立验收证明。
