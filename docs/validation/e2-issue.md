## What to build

E2：让已验收的短会话接续内核作为完整、可核验的 Context Strict 候选包使用。只靠完整包即可在源码目录之外执行接管演示；缺模块、错包或导入后替换不得通过身份核验。根源码是唯一维护来源，生成副本保持一致。

## Acceptance criteria

- [ ] 五个公开入口、能力声明、运行时身份和自包含分发依赖一致；旧合同与门禁保持兼容。
- [ ] 完整候选包的静态校验、构建、验包与源码树外运行通过；缺模块/错包/变更和缺可信验收反例被阻断。
- [ ] 运行说明保持简短，详细协议按需读取，不把本地机制称为真实宿主自动切换。
- [ ] CI增加显式非零测试与源码树外新入口验证，本地复跑并独立审查；远程结果未运行不得声称通过。
- [ ] 完整回归及旧E1安全反例通过，原分发差异消除；不安装、不提交或发布。
