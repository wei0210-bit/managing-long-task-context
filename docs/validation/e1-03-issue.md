## What to build

E1-03：新主控经过实际重验后取得唯一控制权；竞争、崩溃及回执丢失后可以只读确认提交事实，不重复移交。

## Acceptance criteria

- [ ] 激活自行执行核验；检查后证据、授权、合同或代次变化不得凭旧 pass 提交。
- [ ] 两候选竞争最多一方成功、代次恰好增加一次；旧主控迟到请求拒绝，在途正常子任务保留。
- [ ] 同请求重复不重复移交，同 ID 异内容拒绝；普通事件进展不混同控制代次。
- [ ] 用进程屏障控制竞争及真实子进程终止；新进程重读确认已 fsync 的提交，即使快照失败或回执丢失。
- [ ] 日志损坏／不可读返回 unknown，不恢复旧派单、不重试业务；查询无写入。
- [ ] 每种时序有持久化代次／事件及零业务动作证据；机制测试不冒充机器掉电或真实宿主测试。
