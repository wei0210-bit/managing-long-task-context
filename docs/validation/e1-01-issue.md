## What to build

E1-01：只读核验持久化交接资料，明确是否具备接管条件；不授予控制权，不写业务完成。运行时由可信宿主提供身份、许可和内容核验，JSON 自报不能代替。

## Acceptance criteria

- [ ] 有效完整资料通过；必需项缺失、不可读、过期、冲突及错任务／合同／工作区／版本逐类阻断并说明引用。
- [ ] 路径存在、hash 匹配、合法 JSON 或自填 pass 均不能单独通过；无可信核验器保持 unknown。
- [ ] 日志不完整不能借旧快照放行；读取／解析／重建执行冻结资源边界，不截断承重依据。
- [ ] 固定输入重复查询 20 次语义一致，任务状态与业务动作均零写入。
- [ ] E0 v2 冻结预期不可由执行者修改；提供逐行为红绿记录、实际测试命令／结果及案例映射；主控独立复验。
- [ ] 仅隔离本地机制验证；不安装、发布或宣称真实宿主／token 收益。

## Blocked by

None (can start immediately). E0 v2 输入已通过主控复验。

## Execution

Terra-high 新上下文执行；主控在派发附件冻结所有权、接口、命令及失败条件。未验收不得启动下一单。
